# Git Wrapped

Git Wrapped is a planned local-first Rust CLI for turning Git history into shareable analytics and visual reports. See [the handoff spec](git-wrapped-handoff.md) for the product requirements.

This repository currently contains only the initial Cargo workspace scaffold. The CLI does not analyze repositories yet.

## Build and run

With Rust and Cargo installed:

```sh
cargo run
```

The command currently prints a development status message.
